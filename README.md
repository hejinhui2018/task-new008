# 保费方案试算台

面向保险顾问的保费试算页：顾问修改年龄、地区、保障额度或附加险时，页面不仅给出新保费，
还会解释**价格由哪些规则叠加而成**——每条规则的优先级、互斥关系、适用范围都清晰可见。
所有规则与费率数据均为浏览器本地内置的演示数据，无任何网络请求。

技术栈：React 19 + TypeScript + Vite 7，测试使用 Vitest。

## 运行方式

```bash
npm install        # 安装依赖
npm run dev        # 开发模式（默认 http://localhost:5173）
npm test           # 运行全部测试（vitest run）
npm run build      # 类型检查 + 生产构建（输出到 dist/）
npm run preview    # 预览生产构建产物
```

## 页面结构

- **左栏 · 投保条件**：年龄（18–75 周岁）、投保地区、保障额度、附加险（可多选）。
- **中栏 · 方案与保费**：安心基础版 / 守护标准版 / 尊享旗舰版三档方案实时报价；
  下方是**重算历史**，每次变更一条记录，点击可跳回任意历史状态。
- **右栏 · 规则解释**：当前选中方案的完整计算过程——每一步命中的规则、
  调整前/调整后金额、被互斥压制的规则、未生效规则及原因，以及本次「调整前 / 调整后」对照。

任何字段变化都会触发全量重算并同步更新解释。支持撤销 / 重做（`Ctrl/Cmd+Z`、
`Ctrl/Cmd+Shift+Z` 或 `Ctrl+Y`）与一键恢复默认；逐字输入年龄等连续微调会合并为一条历史。

## 规则模型

每条规则（`src/domain/types.ts` 的 `Rule`）包含：

| 属性 | 含义 |
| --- | --- |
| `priority` | 数值越小越先参与计算；互斥冲突时数值大者胜出，相同则按规则编号字典序 |
| `planIds` | 适用范围（缺省为全部方案），范围外的规则标记为「不适用本方案」 |
| `requires` | 求值前必须填写的输入字段，缺失时规则被阻断并明确提示 |
| `conflictsWith` | 互斥规则列表，双方同时命中时低优先级一方被压制并说明原因 |

计算顺序（优先级升序）：基础保费(0) → 年龄费率(10) → 保额档位(20) → 地区系数(30)
→ 附加险(40/45) → 高保额优惠(50)。

## 内置数据

| 类别 | 内容 |
| --- | --- |
| 方案 | 基础版 ¥299 / 标准版 ¥529 / 旗舰版 ¥899（年缴基础保费） |
| 年龄费率 | 18–30 ×1.0 · 31–40 ×1.15 · 41–50 ×1.35 · 51–60 ×1.6 · 61–75 ×2.0（边界值落入较低区间） |
| 地区系数 | 一线城市 ×1.15 · 二线城市 ×1.0 · 三线及以下 ×0.92 |
| 保额档位 | 10 万 ×1.0 · 30 万 ×2.4 · 50 万 ×3.8 · 100 万 ×7.0 |
| 附加险 | 意外医疗 +¥120、意外住院津贴 +¥90、交通意外加倍 +¥110、综合意外升级包 +¥260 |
| 互斥 | 综合意外升级包 ⊕ 意外医疗、综合意外升级包 ⊕ 交通意外加倍（升级包优先级 45 胜出） |
| 适用范围 | 升级包仅标准版/旗舰版可附加；高保额优惠（保额 ≥ 50 万整单 95 折）不适用旗舰版 |

## 目录结构

```
src/
  domain/
    types.ts    # 输入、规则、报价结果的类型定义
    data.ts     # 内置方案、费率表与规则定义（规则由费率表生成）
    engine.ts   # 规则引擎：校验 → 适用范围 → 互斥 → 按优先级叠加
    format.ts   # 金额与效果的展示格式化
  state/
    history.ts  # 重算历史：变更记录、撤销/重做、恢复默认、连续输入合并
  components/   # InputPanel / PlanCards / ExplanationPanel / HistoryPanel
  App.tsx       # 三栏布局与状态编排
src/__tests__/
  engine.test.ts   # 规则优先级、互斥、边界年龄、缺失输入、适用范围
  history.test.ts  # 重算历史：撤销/重做、分支截断、恢复默认、变更说明
```

## 测试

`npm test` 运行 37 个用例，覆盖题目要求的核心场景：

- **规则优先级**：步骤按优先级升序应用；折扣在附加险之后作用于整单；
  自定义规则证明应用顺序由优先级而非规则类型决定。
- **互斥**：升级包压制交通加倍/意外医疗；一对多互斥；同优先级时按规则编号确定胜负。
- **边界年龄**：18/30/31/40/41/50/51/60/61/75 逐档验证，17/76 岁判定为无法承保。
- **缺失输入**：全部缺失与部分缺失时的状态、被阻断规则的标注、部分试算结果。
- **重算历史**：变更追加、撤销/重做后重算结果、撤销后新修改截断分支、
  恢复默认可撤销、连续输入合并、变更说明文案。
